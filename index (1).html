    집계 기준과 자료 범위

    납기
    실제 입고일이 약정 납기일보다 늦으면 지연입니다. 지연 일수 = 실제 입고일 − 약정 납기일, 지연 평균의 분모는 지연 주문 수입니다.
    검사
    검사 이상률은 검사 결과가 ‘정상’이 아닌 주문 수를 전체 입고 주문 수로 나눠 산출합니다.
    중복
    지연과 검사 이상이 같은 주문에서 발생할 수 있습니다(R02). 예외 주문 수는 주문번호 기준으로 중복을 제거합니다.
    처리 상태
    주문 현황 원본의 ‘진행’, ‘완료’를 그대로 표시합니다. 확인 부서·요청 조치·종결 조건은 보고서(구매품질-2026-1121-01) Ⅴ장의 결재 요청안이며, 증빙 검토 후에만 ‘완료’로 변경합니다.
    미확인 항목
    기록에 없는 원인·수량(R02 원인·불량 수량, R03·R07 원인·영향 수량, R06 지연 사유)은 자료 확보 전까지 미확인으로 표시합니다.
    필터 범위
    필터는 주문표와 상세에만 적용됩니다. 상단 지표와 그래프의 기준은 전체 주문입니다.
